# W1 · UI BUILDER (agent: ui-builder, branch w1/ui, budget ~90 min)

Mission: the screen the judges look at for 90 seconds. It renders ONLY contract JSON, runs from fixtures with no backend, and makes the first 10 seconds unforgettable. Visual vocabulary: an exploded stack of layers (our proof), pins and numbered chips on the plan, plain-language findings, a Scan | Our reading | Overlay switch with a wipe slider, an "as of revision" scrubber. Inspired by how Stoa shows sheets, but our own identity.

Read first: `AGENTS.md`, `contracts/proof.py`, `contracts/fixtures/*.json` (skim), `docs/DEMO_SCRIPT.md` (the hook timeline and wow moments).

You own: `web/` only. Stack: Vite + React + TypeScript, plain SVG and CSS 3D transforms, no 3D library. Fonts: system stack plus one local variable font if available; no network at runtime.

## Step 1 · scaffold
`cd web && npm create vite@latest . -- --template react-ts` (or equivalent), `npm i`, add Playwright as a dev dependency for screenshots (`npx playwright install chromium`). Scripts: `dev`, `build`, `typecheck`, `shot`. Generate TypeScript types from the pydantic models: dump `ProofObject.model_json_schema()` and `SheetFacts.model_json_schema()` with a tiny Python script, run `npx --yes json-schema-to-typescript`; if that fails, hand-write `src/types.ts` mirroring `contracts/proof.py` exactly. `src/api.ts` has two modes selected by `VITE_API`: `fixtures` (fetch `/fixtures/*.json`, copied from `contracts/fixtures/` by a `predev` script) and `live` (`http://localhost:8000/api/...`: `analyze`, `ask`, `scale`, `decide`, `cost`). Also load `/claims.json` if present (numbers from the evaluation report).

## Step 2 · components (each in `web/src/components/`, each with a fixture-driven story page at `/#/lab/<name>`)
1. **Stack** — the signature element. One plan exploded into layers (scan, walls, rooms, doors, windows, scale anchors) with `transform-style: preserve-3d`, `rotateX/rotateZ`, layer gap animated by a single `explode` value 0..1. A layer lights up when a number that depends on it is hovered. Must hold 60 fps with 6 layers.
2. **PlanView** — SVG over the image (or a synthetic render of `SheetFacts` polygons when no image exists, with a visible "SYNTHETIC DEMO" ribbon). Numbered chips (1..N) on counted elements; hover on the answer highlights its elements; click pins them. Wipe slider between Scan and Our reading. Licence credit line (`provenance.credit`) always visible under any drawing.
3. **AnswerCard** — big number, interval, tier badge (colour AND icon AND word: "voters agree", "look here first", "cannot answer"), the voters side by side (name, value, runs as a tiny dot strip), "why" in one sentence, cost line `ms · tokens · $`. If `query_spec` is present (planner answer), show it as one readable line, e.g. "counted rooms where type = bedroom and has a window", with a "planned by LLM, computed by code" badge.
4. **ReceiptPanel** — Drawn / Specified / Chosen / Defaulted / Open as five coloured rows listing assumptions with sources; clicking an assumption highlights where it came from.
5. **DecisionCards** — top 3 decisions ranked by impact with a horizontal bar of impact; options as chips; "doesn't fit" options greyed with the reason; a vibe preset row (Budget / Standard / Premium / Nordic) as the alternative lane. The **UncertaintyBand** above the totals collapses with a spring animation when a decision is made.
6. **ScaleAsk** — a modal that appears only when `scale.needs_user`: cheapest question first ("tap a door: is this 0.9 m?"), then draw-a-line, then type-the-scale. Shows the band shrinking after the answer.
7. **FindingsList** — right-hand list in plain language ("7 doors drawn, no schedule: draft ready", "area could be 25-40 m2 until one dimension is known") with severity colour, click = pan to the pin.
8. **CostMeter** — live footer `0 tokens · $0.00 · 412 ms`, animated count-up; totals from `/claims.json` when present, otherwise from the current ProofObject. Never show a number that is not in a ProofObject or claims.json.
9. **TrustLens** — toggle that dims everything except evidence for the selected number.
10. **Hook** — autoplay sequence on first load (skippable with any key): see `docs/DEMO_SCRIPT.md` section "First 10 seconds". Implement as a timeline object (array of `{t, action}`) so timings can be tuned in one place.

## Step 3 · layout
Left: PlanView (largest). Right: tabs Answer | Receipt | Decide | Findings. Top: file name, sheet type, `as of revision` scrubber (disabled with a tooltip until a second revision exists), Scan | Our reading | Overlay switch. Bottom: CostMeter + licence credit. Dark, calm, precise; green = voters agree, amber = look here first, grey = cannot answer; WCAG AA contrast; keyboard accessible (Tab order, Enter to pin, Esc to clear).

## Don'ts
No copying of Stoa's branding or logo. No fake numbers in the UI: everything from fixtures or claims.json, synthetic data always ribboned. No external CDN at runtime. No giant dependencies. Do not edit anything outside `web/`.
